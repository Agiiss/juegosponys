# 🛠️ Herramientas de Desarrollo

Estos archivos son **SOLO para desarrollo y configuración**.

## 📍 Herramientas:

- **viewport-coordinate-picker.html** ⭐ - Marca botones EN PANTALLA
- **coordinate-picker.html** - Marca áreas en imagen original
- **x-coordinate-picker.html** - Marca solo coordenadas X
- **role-generator.html** - Genera roles automáticos

## 🚀 Para usar:

1. Abre cualquiera de estos archivos en tu navegador
2. Marca áreas/botones en la imagen
3. Las coordenadas se guardan en localStorage
4. Se usan automáticamente en index.html

## 📌 NO necesitas estas herramientas para JUGAR

Solo para **configurar nuevos botones o elementos**.

---

Para jugar: **Abre `../index.html`** (en la carpeta padre)
